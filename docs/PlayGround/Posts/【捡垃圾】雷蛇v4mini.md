# 前言

前阵子在出租屋阳台的小空间中，装了一台小主机，所以也就想给它配一个小键盘，正好呢，也是很长时间没玩过新键盘了，于是在闲鱼上逛了一阵子，最终捡到了这把雷蛇黑寡妇v4 mini。

---

# 开箱

快速进行一波开箱。

> 整体外观

紧凑的65%配列，键盘的上方为开关和Type C口，底部中间有一个会发光的雷蛇Logo。

背面，两段式脚撑，以及2.4G收纳仓。

相较于我手里的其他两把键盘，v4mini的会高一些，长度上，这三把键盘几乎是一样的。

> 键帽

这把键盘的键帽很有意思，雷蛇的幽灵键帽，磨砂材质，双层设计。

在不开键盘灯的情况下，字体几乎不可见，开灯后，对应的字符才显现出来。

> 轴体

自带轴体为雷蛇黄轴，简单用了一下感觉很顶手，顺滑度不错。

而且有导光柱，透光度也不错，轴体整体看起来比较饱满。

> 拆解

上灯位 + 全键热插拔。去掉键帽 + 轴体，拧掉螺丝，即可轻松打开。

简单看了下，卖家加了夹心棉、轴下垫和底棉。

---

# 结尾

很久没用过类青轴了，所以在下单这把键盘的同时，我也买了一点极地狐轴，同时买了套便宜的黑色双皮奶键帽，但是装上去后用起来并不舒服，所以保留了几个键位为这个自带的黄轴，其他的键位就换成我那把Keychron Q11上的佳达隆G茶了，以及Q11上那套键帽，发现用起来还不错，整体也比较和谐。

卖家这个兄弟也是很够意思，开始买的时候是说明了不带数据线的。然后大概在我收到货一个月之后，他给我发消息说要把数据线寄给我，我说没必要因为一条线再花运费了，他说没事，这样你后续也好出。

那么以上就是这把键盘的全部内容了，感谢你的收看，我们下期再见吧。
